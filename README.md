# Water

The phone screen is a sealed glass tank of water. Tilt, shake and spin it.

```
npm run dev          # https://localhost:8443 (+ LAN URLs for your phone)
node verify/m2.mjs   # headless verification (Playwright), screenshots in verify/M2/ (m1.mjs for M1)
```

Desktop: move the mouse to tilt gravity, click-drag to shake. `D` or triple-tap a corner toggles the debug overlay.
See `PROGRESS.md` for status.
